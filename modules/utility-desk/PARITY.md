# Utility Desk and Utility Desk Lite comparison

Compared against the original local Utility Desk on October 10, 2026. Utility Desk Lite edition: 1.0.72. This is a browser adaptation, with explicit limits rather than a claim of complete native parity.

| Tool or behavior | Static edition | Difference from the original |
| --- | --- | --- |
| Appearance | Original green palette, breadcrumbs, panels, search, tool layouts and compact mobile navigation; matching sections in the sidebar and Home: Media, documents & images; PDFs; Command planners; Miscellaneous (Date & time and QR generator) | Browser capabilities replace executable checks; activity persists as labels, without native process logs |
| Date & time | Calendar shifts, differences, seconds/milliseconds, IANA timezones, missing-time rejection, earlier/later repeated-time selection, all original world-clock cities | Uses browser timezone data instead of OS Python timezone data |
| Folder sync | Source/destination paths, archive mode, checksums, mirror mode, exclude patterns, copyable dry-run and sync commands | Plans rsync commands; actual comparisons, copying and deletion run in your terminal; the browser requests no folder access |
| Media downloader | yt-dlp command planner for video/audio, quality, single item/playlist, selected positions, download folder, and optional clip range | Commands run locally with yt-dlp and FFmpeg; no browser download, metadata fetch or path checks |
| Secure copy | Upload/download command planner, file/folder, times/permissions option, username and port, validated paths, command copy | Actual SCP and SSH-agent access require a local SSH client; no connection, credential or key input; inputs are not persisted |
| Media converter | MP4/MKV H.264/AAC, WebM VP9/Opus, MP3/M4A/WAV/Opus, extra OGG/GIF, quality, maximum height, audio bitrate, From/To, browser duration detection, filename, preview, progress and cancel | Bundled single-thread FFmpeg; 256 MB input limit; blank To converts through the source’s end, with detected duration shown as a hint; metadata detection uses browser playback instead of ffprobe; no native output-folder selection |
| Document converter | TXT/Markdown/HTML/basic EPUB/classic MOBI, PDF → EPUB/Markdown/text/HTML, EPUB/Markdown → searchable paginated A4 PDF, title/author, filename and text preview | Text reflow only: no OCR, images, exact PDF layout, complex tables, AZW3/KF8, DRM or Calibre fidelity; 50 MB, 1,000 PDF pages and 2 million text characters; PDF fonts cover Latin, Greek and Cyrillic, with unsupported glyphs reported |
| PDF to images | PNG/JPEG, 72–1,200 DPI, JPEG quality, selected pages, crop-box rendering, annotation toggle, previews, individual/ZIP downloads, bundled fonts/CMaps | TIFF export and full media-box option unavailable; 50 MP per-page memory guard; PDF.js instead of Poppler |
| Images to PDF | Ordered inputs, image-sized/A4/Letter and extra paper sizes, orientation, DPI, fitting, margin, filename, previews | Browser-decodable formats only, no TIFF/RAW/HEIC; browser PDF generation instead of ImageMagick |
| Merge PDFs | Reordering, selected pages in entered order including repetitions, filename; waits for selected batches to finish validation | Unencrypted inputs, size guards; document-level bookmarks and metadata are omitted; forms/links may need review |
| Split PDF | Selected pages in both modes; separate files deduplicate/use original page numbers; one-file extraction preserves entered order/repetitions; preview and ZIP | Unencrypted inputs, browser downloads instead of new native output folder; bookmarks/metadata omitted |
| Compress PDF | Lossless stream/object optimization retaining text, metadata, links and forms; balanced/smaller-file JPEG page modes, actual size/savings, cancellation, download and unchanged-copy fallback | Native qpdf modes preserve text and optimize eligible non-JPEG images. Browser image modes rasterize visible crop-box pages at 150/96 DPI, flatten links/forms and remove selectable text; 200 MB, 1,000 pages, 50 MP per rendered page |
| Unlock PDF | Known opening/owner password or empty-password decryption; pages, metadata, links and forms retained; cancellable worker; passwords never persisted | Bundled @cantoo/pdf-lib instead of local qpdf; 200 MB and 1,000-page limits; no local output-folder selection |
| QR generator | Type dropdown for text/links, Wi-Fi (WPA/WPA2, WEP, open, hidden), email, phone, SMS and vCard contacts; PNG/SVG export, size and error correction, four-module quiet zone | Same qrcode library, entirely local in both editions |
| Crop Image | Separate utility with one original-image crop preview, kept dimensions, removed-edge pixels and area percentage; exact crop export as PNG/JPEG/WebP; camera orientation applied | Browser-decodable inputs and 100 MP limit; native uses ImageMagick and also exports TIFF/GIF/BMP/AVIF |
| Compress Image | Separate utility matching Compress PDF layout; optional maximum bounds/enlargement or exact crop/padding/stretch, live output dimensions, JPEG/WebP quality slider (1–100, default 75), lossless PNG, strict decimal KB/MB limit, original/output sizes and dimensions, actual savings, output filename, progress and cancellation | PNG/JPEG/WebP output only; browser-decodable inputs, 200 MB and 100 MP source/output limits; dimensions stay unchanged unless resizing is enabled; metadata removed and camera orientation applied; JPEG source transparency stays white even with black padding; animated inputs export a single frame |
| Image workshop | Adjacent Rotate clockwise and Flip dropdowns (No flip/Horizontal/Vertical/Both), one Color style dropdown (Original colors/Grayscale/Sepia), separate automatic/manual contrast and sharpening, high-quality export, preview and reset at the source dimensions; JPEG transparency becomes white after effects; resizing, compression quality and size limits moved to Compress Image | PNG/JPEG/WebP output only; browser-decodable inputs only; no native GIF/TIFF/BMP/AVIF encoder; camera orientation is corrected automatically rather than optionally, metadata stripping is automatic, retaining EXIF/profiles is unavailable |
| Cancellation and state | One operation at a time; controls frozen while running; cancellation on navigation; pending image/PDF canvas encoders release immediately and ignore late output; source-based filenames survive same-source reselection; form drafts flush on navigation | Browser decoding and individual pdf-lib steps cannot always be interrupted; command planners do not run operations |
| Hosting | Committed `site/`, manual workflow on `master`, only `site/` uploaded | Same distribution flow as Drafts; no backend, CDN, runtime package installation or cross-origin isolation headers |

Browser assets are fetched from the same hosting origin. File contents are processed locally. A static host cannot access arbitrary local paths or invoke the original system executables.

Automated tests exercise date/time edges, PDF order and repetitions, rsync/yt-dlp command options, shell quoting, image geometry and size limits, document/MOBI round trips and metadata, transfer validation, and task/form lifecycle. Browser verification and its limits are recorded in README.md.

Command planners use macOS/Linux shell quoting. Inputs are not persisted. The rsync preview is a dry-run command to execute locally, rather than a browser-generated list of file changes. See the [rsync manual](https://download.samba.org/pub/rsync/rsync.1) and [yt-dlp options](https://github.com/yt-dlp/yt-dlp#usage-and-options).
